# Computer Networks Lab Programs (Experiments 7–15)

This bundle contains runnable Python programs, Wireshark filter references, and configuration/lab guides for experiments 7–15.

## Requirements
- Python 3.9 or newer
- No third-party Python packages are required for experiments 7–10 and the LAN topology benchmark.
- Wireshark (and optionally `tshark`) is required for experiments 11–13.
- Cisco Packet Tracer is required to build and save the `.pkt` file for experiment 14.

## Run the Python programs
Open a terminal in the relevant folder and run:

```bash
python tcp_udp_simulation.py
python routing_simulation.py
python dns_lookup.py
python crc_demo.py
python rtp_analyzer.py --help
python lan_benchmark.py
```

On some systems, use `python3` instead of `python`.

## Important notes
- CRC is an **error-detection** method. It can detect many transmission errors, but it does not itself correct corrupted bits. The CRC program demonstrates detection by comparing the received frame's remainder with zero.
- The TCP/UDP program is a simplified educational simulator, not a full TCP/IP stack or a replacement for NS-3/OMNeT++.
- RTP delay analysis needs RTP sequence-number and timestamp fields. Export those fields from Wireshark/tshark as CSV and pass the CSV to the analyzer.
- Packet capture may require administrator/root privileges. Capture only traffic on networks/devices you own or are authorized to inspect.
- The Packet Tracer guide provides a topology and device configurations. Open Cisco Packet Tracer and save your completed topology as `simple_network.pkt`; a `.pkt` file is a Cisco application project and is not generated by this Python bundle.
